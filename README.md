# 🎮 Frontend Mini Games

纯前端实现的经典小游戏合集，零依赖、单文件、开箱即玩。

## 🕹️ 游戏列表

### 2048

经典的数字合并游戏。使用方向键滑动方块，相同数字碰撞合并加倍，冲击 2048！

- 📁 [game-2048/index.html](./game-2048/index.html)

**特性**

- ✨ 方块滑动过渡、合并弹跳、新方块出现动画
- ⚡ 实时得分 + 最高分（localStorage 持久化）
- 🏆 达成 2048 显示胜利提示，可继续挑战更高分
- 📱 手机端四方向滑动手势支持
- 🎨 按数值渐变的经典暖色调配色

### 贪吃蛇（Snake）

经典街机游戏。控制小蛇吃食物不断变长，撞墙或咬到自己则游戏结束。

- 📁 [snake-game/index.html](./snake-game/index.html)

**特性**

- ✨ 渐变发光蛇身、带眼睛的蛇头、发光食物
- ⚡ 每 50 分自动提速一档，速度等级实时显示
- 🏆 最高分（localStorage 持久化），破纪录提示
- ⏸️ 空格键暂停 / 继续
- 📱 手机端滑动手势支持

## 🚀 快速开始

无需安装任何依赖，两种方式任选：

**方式一：直接打开**

下载或克隆仓库后，双击任意游戏的 `index.html` 用浏览器打开即可。

```bash
git clone git@github.com:Liora118/2048.git
```

**方式二：本地服务器**

```bash
cd 仓库目录
python -m http.server 8899
# 浏览器访问 http://127.0.0.1:8899/game-2048/ 或 /snake-game/
```

## 🎮 操作说明

| 游戏 | 键盘 | 触屏 |
|------|------|------|
| 2048 | `↑ ↓ ← →` 或 `W A S D` | 四方向滑动 |
| 贪吃蛇 | `↑ ↓ ← →` / `W A S D`，`空格` 暂停 | 滑动控制方向 |

## 🛠️ 技术栈

- 原生 HTML + CSS + JavaScript，无任何框架和第三方依赖
- 贪吃蛇：Canvas 渲染
- 2048：DOM + CSS 动画
